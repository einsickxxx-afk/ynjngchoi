매주 반복되는 근무실적 취합·보고 업무를 하나의 화면으로 옮긴 과정과, 앞으로의 활용 방향을 공유드립니다.

Part 1 · 시작

기존 방식의 한계

  • 수작업 취합

    주차마다 엑셀 원본을 열어 피벗과 필터를 새로 걸어야 했고, 사람이 직접 52시간 초과자를 골라내는 과정이 반복됐습니다.

  • 공유의 어려움

    엑셀 파일을 그대로 넘기면 팀별로 보이지 않아도 될 데이터까지 함께 노출되는 문제가 있었습니다.

  • 추이 파악의 한계

    한 주 스냅샷만으로는 특정 인원이 몇 주째 연속으로 52시간을 넘기고 있는지 즉시 알기 어려웠습니다.

  • 목표

    엑셀 데이터를 붙여넣기만 하면, 위험군·추이·부서 비교가 자동으로 계산되는 화면을 만드는 것.

Part 2 · 개발 과정

01 — 데이터를 파일 안에 내장

const EMBEDDED_SAMPLE_CSV = \`No.,구분,년월,주차, 사번,이름,직급,사업장,부서명, 월,화,수,목,금,토,일, ...\`;
  • 엑셀 → CSV 변환

    전사명부·근무실적 원본(xlsx)을 정리해 CSV 텍스트로 바꾸고 파일 안에 그대로 붙여 넣었습니다.

  • 즉시 표시

    파일을 열면 서버 요청 없이 바로 데이터가 보이도록 했습니다.

  • 자체 CSV 파서

    외부 라이브러리 없이 따옴표·쉼표를 처리하는 파서를 직접 구현했습니다.

Part 2 · 개발 과정

02 — 필터링·집계 규칙 정의

52h

2주+
연속 52시간 초과가 2주 이상 이어지면 위험군 테이블에 노출됩니다.
자동제외
근태예외자, 상무 이상 임원은 모든 집계에서 자동으로 빠집니다.

Part 3 · 추후 활용 방안

앞으로의 활용 계획

단기
팀별 배포 정례화

매주 데이터 갱신 후 "완성 파일로 저장"으로 팀장 배포용 파일을 자동 생성합니다.

중기
인사 변동 추적 연동

휴직·복직·퇴직 등 인사 변동 기준일 조회 기능과 결합해 근무실적 변화를 함께 설명할 수 있도록 확장합니다.

장기
이직 위험 신호 결합

승진 대기 기간, 평가 이력 등 고신호 변수를 함께 보여줘 근무실적을 조기경보 지표로 발전시킵니다.

Part 3 · 추후 활용 방안

한 줄 요약

단일 HTML 파일 안에 데이터 · 계산 로직 · 화면이 모두 들어있어, 서버 없이도 매주 갱신·배포가 가능한 구조입니다.

운영 부담 최소화엑셀 파일 하나만 새로 붙여 넣으면 전체 화면이 재계산됩니다.
보안 · 배포 편의팀별 필터 결과만 골라 별도 파일로 내보낼 수 있습니다.
확장 가능성동일 구조에 인사 데이터를 추가로 결합할 수 있습니다.
