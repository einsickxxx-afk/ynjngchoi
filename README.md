# 해양사업부 발표_인터랙티브.html 사용 안내

## 이 파일은 무엇인가요

해양사업부 근무실적 현황 대시보드의 구조를 설명하는 발표용 웹페이지입니다. 파워포인트 대신 브라우저에서 여는 HTML 파일 한 장으로, 시작 → 개발 과정 → 추후 활용 방안 3부 10장으로 구성되어 있습니다. 인터넷 연결 없이도 대부분 동작하지만, 글꼴은 구글 폰트를 불러오므로 처음 열 때는 인터넷이 연결된 상태를 권장합니다.

## 여는 방법

파일을 더블클릭하면 기본 브라우저(Chrome, Edge 등)로 바로 열립니다. 별도 프로그램 설치나 서버 실행이 필요 없습니다.

## 발표 중 조작 방법

| 동작 | 방법 |
|---|---|
| 다음 슬라이드 | 오른쪽 화살표 키, 스페이스바, 하단 › 버튼 |
| 이전 슬라이드 | 왼쪽 화살표 키, 하단 ‹ 버튼 |
| 특정 슬라이드로 이동 | 하단 점(dot) 클릭 |
| 처음 / 마지막으로 | Home / End 키 |
| 트랙패드로 넘기기 | 좌우로 스크롤 |
| 모바일에서 넘기기 | 화면을 좌우로 스와이프 |
| 카드 상세 설명 보기 | 클릭 가능한 카드(테두리 위에 마우스를 올리면 밝아지는 카드) 클릭 |
| 상세 설명 닫기 | 팝업 우측 상단 ✕, 팝업 바깥 클릭, 또는 ESC 키 |

화면 좌측 상단에는 현재 파트(시작 / 개발 과정 / 추후 활용 방안)가, 우측 상단에는 몇 번째 슬라이드인지가 표시됩니다.

## 색상 바꾸는 방법

파일을 텍스트 편집기(메모장, VS Code 등)로 열면 맨 위 `<style>` 태그 바로 아래 `:root { ... }` 부분에 색상 값이 모여 있습니다.

```css
:root{
  --bg:        #0A1220;   /* 전체 배경 */
  --panel:     #0F1B2E;   /* 카드 배경 */
  --coral:     #E2646C;   /* 강조색 */
  --sky:       #8FB4D9;   /* 강조색 */
  --amber:     #E8A94C;   /* 강조색 */
  --text:      #DCE6F2;   /* 본문 글자색 */
  --muted:     #7C93AF;   /* 흐린 설명 글자색 */

  --act1: var(--amber);   /* 시작 파트 색 */
  --act2: var(--coral);   /* 개발 과정 파트 색 */
  --act3: var(--sky);     /* 추후 활용 방안 파트 색 */
}
```

원하는 항목의 HEX 값(`#`으로 시작하는 여섯 자리 코드)만 바꾸면 파일을 저장하고 새로고침했을 때 전체 테마에 바로 반영됩니다. 다른 코드는 건드리지 않아도 됩니다.

파트별로 강조색을 다르게 주고 싶다면 `--act1`, `--act2`, `--act3` 값을 원하는 색 이름이나 HEX 코드로 바꾸면 됩니다. 파트가 바뀔 때 상단 라벨과 진행바 색이 그 값을 따라갑니다.

## 슬라이드 내용 수정하는 방법

슬라이드 하나는 아래 형태의 덩어리 하나입니다.

```html
<section class="slide" data-act="1">
  <div class="slide-inner">
    ... 내용 ...
  </div>
</section>
```

- 글자만 바꾸려면 태그 안 한글 텍스트만 수정하면 됩니다. `class="..."` 부분은 디자인과 연결되어 있으니 그대로 둡니다.
- `data-act` 값은 `"1"`(시작) / `"2"`(개발 과정) / `"3"`(추후 활용 방안) 중 하나로, 이 값에 따라 상단 라벨과 색이 자동으로 정해집니다.
- 슬라이드를 추가하려면 `<section>`부터 `</section>`까지 통째로 복사해서 원하는 위치에 붙여넣으면 됩니다. 순서, 페이지 번호, 하단 점(dot) 개수는 모두 자동으로 다시 계산됩니다.
- 슬라이드를 삭제하려면 해당 `<section>...</section>` 전체를 지우면 됩니다.

## 클릭하면 열리는 상세 설명(팝업) 추가하는 방법

카드나 목록 항목에 `class="expandable"`을 추가하고 `data-title`, `data-body` 두 속성을 채우면 클릭 시 자동으로 팝업이 뜹니다.

```html
<div class="bignum expandable"
     data-title="팝업 제목"
     data-body="<p>첫 번째 설명 문단</p><p>두 번째 설명 문단</p>">
  <div class="n">화면에 보이는 짧은 숫자</div>
  <div class="l">화면에 보이는 짧은 설명</div>
</div>
```

주의할 점은 다음과 같습니다.

- `data-body` 안에서는 큰따옴표(`"`)를 쓰면 속성이 깨지므로, 문장 안에서 따옴표가 필요하면 작은따옴표(`'`)를 사용합니다.
- 설명을 여러 문단으로 나누고 싶으면 `<p>...</p>`를 이어서 여러 개 씁니다.
- 이미 만들어진 `rail-step`, `bignum`, `cell`, `tl-item`, `col-list li` 같은 카드에 이 두 속성만 추가해도 바로 클릭 가능해집니다.

## 자주 하는 실수

- `data-body` 안에서 큰따옴표를 그대로 쓰면 그 지점에서 속성이 끊겨 팝업 내용이 깨집니다. 작은따옴표로 바꿔서 씁니다.
- `<section>` 태그의 여는 태그와 닫는 태그 중 하나만 지우면 이후 슬라이드가 전부 어긋나 보일 수 있습니다. 항상 짝을 맞춰 지우고 붙여넣습니다.
- 색상 HEX 코드 앞의 `#`을 빠뜨리면 색이 적용되지 않습니다.

## 파일 구성 요약

- HTML, CSS, JavaScript가 파일 하나에 모두 들어있는 단일 파일입니다.
- 외부 라이브러리 없이 순수 JavaScript로 슬라이드 전환, 진행바, 팝업을 구현했습니다.
- 유일한 외부 의존은 구글 폰트(IBM Plex Sans KR, JetBrains Mono)이며, 인터넷이 없으면 시스템 기본 글꼴로 대체되어 표시됩니다.
