01 · Data

데이터가 코드 안에 내장돼 있습니다

const EMBEDDED_SAMPLE_CSV = \`No.,구분,년월,주차, 사번,이름,직급,사업장,부서명, 월,화,수,목,금,토,일, ...\`;
  • 내장 데이터

    388행 부근, 백틱 문자열 하나에 CSV 원문 약 1,300줄이 그대로 들어있습니다. 서버 요청 없이 즉시 표시됩니다.

  • CSV 불러오기

    파일 시그니처로 xlsx 오업로드를 감지하고, UTF-8 / UTF-16 / EUC-KR 인코딩을 자동 판별합니다.

  • 자체 CSV 파서

    외부 라이브러리 없이 따옴표·쉼표를 문자 단위로 처리하는 parseCSV()가 직접 구현되어 있습니다.

02 · Filter & Aggregate

render() 하나가 모든 계산의 시작점

let rows = RAW_ROWS.filter(r => r['구분'] !== EXCLUDE_WORKTYPE && !EXEC_RANKS.includes(r['직급']) ); // 사업장 · 부서 필터 → 주차별 그룹핑 // → 최신 주차 추출 → 8개 함수 호출
  • 자동 제외 규칙

    근태예외자, 상무·전무·부사장·전문위원은 모든 통계에서 항상 빠집니다.

  • 주차 정렬 키

    weekKey()가 "3주차(06.15~06.21)" 같은 텍스트를 "202606-03" 형태로 바꿔 정렬합니다.

  • 사업부 전체 비교

    필터를 걸어도 orgLatestRows로 사업부 전체 평균을 함께 계산해 비교 막대를 만듭니다.

04 · UI

React 없이 흉내 낸 단방향 리렌더링

카드들은 자기만의 상태를 갖지 않습니다. render()가 새로 계산한 배열을 넘기면, 각 함수는 매번 자신이 담당하는 DOM을 innerHTML로 통째로 다시 씁니다.

  • KPI 카드 4개

    #kpiCount · #kpiRisk · #kpiAvg · #kpiWeekend

  • 차트 카드 4개

    #trendChart · #deptRanking · #bucketPie · #siteRanking

  • 요일·주말 카드 2개

    #weekdayChart · #weekendStat

  • 상세 테이블

    #riskTableBody — 위험군 인원 리스트

Summary

한 줄 요약

단일 HTML 파일 안에 데이터(EMBEDDED_SAMPLE_CSV) · 계산 로직(render 파이프라인) · 화면(8개 렌더 함수)이 모두 들어있고, "저장"을 누르면 지금 화면 상태를 데이터까지 포함해 다시 파일로 박아내는 구조입니다.

52시간 기준선주확정근무시간이 3,120분(52시간)을 넘는 인원을 모든 차트의 위험 기준으로 사용합니다.
제외 규칙근태예외자, 상무 이상 임원은 전 화면에서 자동 제외됩니다.
위험군 정의최신 주차부터 역순으로 52시간 이상이 2주 이상 끊기지 않아야 위험군입니다.
